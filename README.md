# TGT Analysis & Engagement Module

This project is a web-based module for analyzing and engaging targets (TGT). It includes features for displaying target lists, calculating engagement counts, and updating tables based on user interactions.

https://tgt-analysis-prod.netlify.app/

## Features

- Display target lists with various attributes.
- Calculate and display engagement counts for different target categories.
- Update engagement counts dynamically based on user interactions (checkbox selections).

## Prerequisites

- [Node.js](https://nodejs.org/) (for any build processes, if applicable)
- [Git](https://git-scm.com/) (for version control)
- [Netlify](https://www.netlify.com/) account (for deployment)
